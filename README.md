# Our Autumn Escape · Hudson Valley Day Trip

A three-stop October 24, 2026 itinerary from Jersey City, designed for GitHub Pages. Departure: **1:30 PM**. Return home the same night.

## Pages

- `index.html` — Quick View (default) and Full Details toggle
- `details.html` — Full Details opens directly, useful if a browser blocks in-page interaction
- `extreme.html` — Stop-by-stop ordered sequence, GPS navigation, parking and backup plans

## Publish on GitHub Pages

1. Keep these files at the root of the public `abhithaparian/SharePlan` repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then select **Save**.
4. The site URL will be `https://abhithaparian.github.io/SharePlan/`. There can be a short propagation delay.

No build step, API keys, or JavaScript required to change pages. All page-to-page links are relative and compatible with project-site paths. Images use externally hosted URLs; viewing the site fully requires an internet connection. Reservations are not made by this site.
